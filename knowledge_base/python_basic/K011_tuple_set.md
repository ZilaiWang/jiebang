# K011 元组与集合

## 1. 核心定义

元组是有序且通常不可变的数据容器。

## 2. 必须掌握

- 元组是有序且通常不可变的数据容器。
- 集合用于保存不重复元素。
- 集合适合做去重和成员判断。

## 3. 示例

### 用元组表示固定坐标

```python
point = (3, 5)
x, y = point
print("坐标：", x, y)

# 元组不可修改，以下代码会报错：
# point[0] = 10  # TypeError
```

元组适合存储不应被修改的固定数据，如坐标、日期、配置常量。

### 用集合去重

```python
scores = [85, 92, 85, 78, 92, 85]
unique_scores = set(scores)
print("去重后的成绩：", unique_scores)

# 成员判断
if 85 in unique_scores:
    print("有 85 分这个成绩")
```

集合自动去除重复元素，适合数据去重和快速成员检查。

## 4. 常见错误

- 试图修改元组元素（如 t[0]=1），忘记元组是不可变类型。
- 用 {} 创建空集合适得其反——{} 是空字典，应使用 set()。
- 认为集合有序，实际集合是无序的，多次打印顺序可能不同。
