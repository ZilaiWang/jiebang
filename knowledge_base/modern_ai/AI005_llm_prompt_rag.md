# AI005 大语言模型、提示词与 RAG

## 1. 核心定义

大语言模型根据上下文生成文本，但可能产生不受证据支持的幻觉内容。

## 2. 必须掌握

- 大语言模型根据上下文生成文本。
- RAG 通过检索外部知识为生成过程提供证据。
- 幻觉是指模型生成了不受可靠证据支持的内容。
