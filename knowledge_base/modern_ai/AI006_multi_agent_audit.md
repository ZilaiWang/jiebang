# AI006 多智能体协作与事实审核

## 1. 核心定义

多智能体系统通过职责分工让不同 Agent 执行诊断、生成、审核和决策。

## 2. 必须掌握

- 多智能体系统通过职责分工让不同 Agent 执行不同任务。
- 事实审核 Agent 用于检查生成内容是否受到证据支持。
- 生成、审核和决策分离可以降低单一生成模块直接发布错误内容的风险。

## 3. 示例

### 教学示例

# 该示例用于辅助理解“多智能体协作与事实审核”，正式代码题由题库 schema 单独约束。

不同 Agent 分别负责学情诊断、内容生成、事实审核和下一步学习决策。

## 4. 常见错误

- 把概念背成口号，不区分输入、输出、证据和评价边界。
- 生成题目时不绑定 source_id/fact_id，导致 Role A 无法事实审核。
