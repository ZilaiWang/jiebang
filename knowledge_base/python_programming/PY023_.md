# PY023 字符串格式化

- 模块：Python程序设计
- 难度：basic
- 摘要：f-string 可把变量值嵌入字符串。

## 可审核事实
- PY023:F001 — f-string 可把变量值嵌入字符串。
- PY023:F002 — 格式化输出可控制数值的小数位数。
- PY023:F003 — 字符串格式化适合生成结构清晰的文本报告。

## 教学示例

### 生成成绩报告

```python
name = "小明"
score = 92.5
rank = 3
line = f"{name} 的成绩是 {score:.1f}，排名第 {rank}"
print(line)
```

f-string 在字符串中嵌入变量，{score:.1f} 控制成绩保留一位小数。

## 练习任务
- 用 f-string 输出姓名和成绩
- 把平均分格式化为保留两位小数
