# PY028 类与实例

- 模块：Python程序设计
- 难度：intermediate
- 摘要：class 用于定义类，实例是由类创建的对象。

## 可审核事实
- PY028:F001 — class 用于定义类，实例是由类创建的对象。
- PY028:F002 — 实例属性用于保存对象自身的数据。
- PY028:F003 — 面向对象程序设计适合把数据和相关操作组织在一起。

## 教学示例

### 定义学生类

```python
class Student:
    def __init__(self, name, score):
        self.name = name
        self.score = score

student = Student("小明", 92)
print(student.name, student.score)
```

Student 是类，student 是实例，name 和 score 是实例属性。
