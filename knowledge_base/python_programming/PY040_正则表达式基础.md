# PY040 正则表达式基础

- 模块：Python程序设计
- 难度：intermediate

## 可审核事实
- PY040:F001 — 正则表达式用于描述文本匹配模式。
- PY040:F002 — re 模块提供 Python 中常用的正则表达式功能。
- PY040:F003 — findall 可返回文本中所有匹配结果。

## 教学示例

```python
import re

text = "A12 B7 C305"
numbers = re.findall(r"\d+", text)
print(numbers)
```
