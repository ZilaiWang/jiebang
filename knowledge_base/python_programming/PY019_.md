# PY019 切片进阶

- 模块：Python程序设计
- 难度：basic
- 摘要：切片可从序列中取出指定范围的元素。

## 可审核事实
- PY019:F001 — 切片可从序列中取出指定范围的元素。
- PY019:F002 — 切片语法通常使用 start:stop 表示左闭右开的范围。
- PY019:F003 — 切片可以设置步长来间隔取值。

## 教学示例

### 提取成绩片段和倒序文本

```python
scores = [72, 85, 91, 64, 88]
top_middle = scores[1:4]
text = "Python"
reversed_text = text[::-1]
print(top_middle)
print(reversed_text)
```

scores[1:4] 取出索引 1 到 3 的元素，text[::-1] 使用负步长得到反向字符串。

## 练习任务
- 给定列表 scores，取出第 2 到第 4 个成绩
- 给定字符串 text，使用切片得到倒序字符串

## 题目种子
- L1 `choice`：表达式 [10,20,30,40][1:3] 的结果是什么？（答案：[20,30]；引用：PY019:F002）
- L2 `short_answer`：说明切片 start:stop 为什么通常不包含 stop 位置。（答案：切片 start:stop 表示左闭右开的范围。；引用：PY019:F002）
- L2 `debugging`：判断正误：[1,2,3][0:2] 会得到 [1,2,3]。（答案：错误。0:2 不包含索引 2，结果是 [1,2]。；引用：PY019:F002）
- L3 `practice`：写代码返回字符串 s 的倒序结果。（答案：能使用 s[::-1] 或等价切片。；引用：PY019:F003）
