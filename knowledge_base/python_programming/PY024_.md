# PY024 文件逐行处理

- 模块：Python程序设计
- 难度：intermediate
- 摘要：可以用 for line in file 逐行读取文本文件。

## 可审核事实
- PY024:F001 — 可以用 for line in file 逐行读取文本文件。
- PY024:F002 — strip 可去除字符串首尾的空白字符。
- PY024:F003 — 逐行处理适合统计行数或解析每一行记录。

## 教学示例

### 逐行统计有效记录

```python
count = 0
with open("scores.txt", "r", encoding="utf-8") as f:
    for line in f:
        line = line.strip()
        if line:
            count += 1
print(count)
```

for line in f 逐行读取文件，strip 去掉换行符和空白，再统计非空行。
