# PY052 表结构与字段

- 模块：Python程序设计
- 难度：intermediate
- 来源范围：Python程序设计基础教程 / 基于数据库的持久化

## 可审核事实
- PY052:F001 — 数据库表结构定义了记录包含哪些字段。
- PY052:F002 — CREATE TABLE 语句可创建数据表。
- PY052:F003 — 主键字段常用于唯一标识一条记录。

## 教学示例

```python
create_sql = """
CREATE TABLE students (
    id INTEGER PRIMARY KEY,
    name TEXT,
    score REAL
)
"""
print(create_sql)
```

students 表包含 id、name、score 三个字段，id 作为主键。

## 练习任务
- 设计学生成绩表的字段
- 写出 CREATE TABLE 建表语句

## 题目种子
- `choice`：唯一标识一条记录常用什么字段？（答案：主键字段）
- `short_answer`：CREATE TABLE 的作用是什么？（答案：CREATE TABLE 语句可创建数据表。）
- `debugging`：判断正误：表结构不需要定义字段。（答案：错误。数据库表结构定义了记录包含哪些字段。）
- `practice`：写出包含 id/name/score 的 students 表结构。（答案：能写出 CREATE TABLE 和字段定义。）
