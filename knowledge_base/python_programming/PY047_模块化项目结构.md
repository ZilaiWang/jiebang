# PY047 模块化项目结构

- 模块：Python程序设计
- 难度：intermediate

## 可审核事实
- PY047:F001 — 模块化项目结构把入口程序和工具函数分开组织。
- PY047:F002 — main 文件通常负责组织流程。
- PY047:F003 — 工具模块通常保存可复用函数。

## 教学示例

```python
# score_tools.py
def average(scores):
    return sum(scores) / len(scores)

# main.py
scores = [80, 90, 70]
print(average(scores))
```
