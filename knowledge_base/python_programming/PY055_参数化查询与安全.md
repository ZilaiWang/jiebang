# PY055 参数化查询与安全

- 模块：Python程序设计
- 难度：intermediate
- 来源范围：Python程序设计基础教程 / 基于数据库的持久化

## 可审核事实
- PY055:F001 — 参数化查询把 SQL 模板和参数值分开传入。
- PY055:F002 — 使用占位符传参可降低 SQL 注入风险。
- PY055:F003 — 不要把用户输入直接拼接进 SQL 字符串。

## 教学示例

```python
sql = "SELECT score FROM students WHERE name = ?"
params = ("小明",)
print(sql, params)
```

? 是占位符，用户输入通过参数传入而不是拼接到 SQL 中。

## 练习任务
- 把用户输入作为参数传入查询语句
- 说明为什么不要直接拼接 SQL 字符串

## 题目种子
- `choice`：降低 SQL 注入风险的常见做法是什么？（答案：使用占位符传参）
- `short_answer`：参数化查询是什么意思？（答案：参数化查询把 SQL 模板和参数值分开传入。）
- `debugging`：判断正误：可以把用户输入直接拼接进 SQL 字符串。（答案：错误。不要把用户输入直接拼接进 SQL 字符串。）
- `practice`：写出按姓名查询成绩的参数化 SQL 思路。（答案：能使用占位符和参数元组。）
