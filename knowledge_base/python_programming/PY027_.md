# PY027 模块化程序设计

- 模块：Python程序设计
- 难度：intermediate
- 摘要：模块化程序设计把相关函数和数据组织到模块中。

## 可审核事实
- PY027:F001 — 模块化程序设计把相关函数和数据组织到模块中。
- PY027:F002 — import 可在一个文件中使用另一个模块提供的功能。
- PY027:F003 — 模块化有助于复用代码并降低单个文件复杂度。

## 教学示例

### 把成绩计算封装到模块思路中

```python
# score_tools.py
def average(scores):
    return sum(scores) / len(scores)

# main.py
# from score_tools import average
print(average([80, 90, 75]))
```

把 average 放入工具模块，主程序通过 import 使用，有助于复用和组织代码。

## 练习任务
- 把成绩计算函数整理到单独模块
- 在主程序中导入并调用自定义模块函数
