# PY025 函数默认参数

- 模块：Python程序设计
- 难度：intermediate
- 摘要：函数参数可以设置默认值，使调用时可省略对应实参。

## 可审核事实
- PY025:F001 — 函数参数可以设置默认值，使调用时可省略对应实参。
- PY025:F002 — 关键字参数可通过参数名指定传入的值。
- PY025:F003 — 默认参数适合表达常用配置或可选输入。

## 教学示例

### 带默认等级的成绩格式化函数

```python
def format_score(name, score, level="普通"):
    return f"{name}:{score}:{level}"

print(format_score("小明", 92))
print(format_score("小红", 95, level="优秀"))
```

level 有默认值，调用时可省略；也可用关键字参数明确指定。
