# PY030 继承与方法重写

- 模块：Python程序设计
- 难度：intermediate
- 摘要：继承可让子类复用父类已有属性和方法。

## 可审核事实
- PY030:F001 — 继承可让子类复用父类已有属性和方法。
- PY030:F002 — 子类可以定义自己的方法来扩展父类功能。
- PY030:F003 — 方法重写可让子类提供与父类不同的实现。

## 教学示例

### 优秀学生类扩展基础学生类

```python
class Student:
    def describe(self):
        return "普通学生"

class HonorStudent(Student):
    def describe(self):
        return "优秀学生"

student = HonorStudent()
print(student.describe())
```

HonorStudent 继承 Student，并重写 describe 方法返回不同描述。

## 练习任务
- 定义子类继承父类并添加新方法
- 重写父类方法返回不同文本
