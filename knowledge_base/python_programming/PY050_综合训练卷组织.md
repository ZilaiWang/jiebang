# PY050 综合训练卷组织

- 模块：Python程序设计
- 难度：integrated

## 可审核事实
- PY050:F001 — 综合训练卷应覆盖多个知识点而不是只考单一概念。
- PY050:F002 — 训练卷可按诊断、训练和考试用途组织题目。
- PY050:F003 — 综合训练卷应保留每题的 source_id 和 fact_id 以便审核。

## 教学示例

```python

    "exam": ["Q3"],
}
print(paper)
```
