# PY020 列表推导式

- 模块：Python程序设计
- 难度：basic
- 摘要：列表推导式可用简洁语法从可迭代对象生成列表。

## 可审核事实
- PY020:F001 — 列表推导式可用简洁语法从可迭代对象生成列表。
- PY020:F002 — 列表推导式可以在生成元素时加入条件筛选。
- PY020:F003 — 列表推导式适合表达简单的映射和筛选逻辑。

## 教学示例

### 筛选及格成绩

```python
scores = [58, 76, 90, 45, 82]
passed = [score for score in scores if score >= 60]
doubled = [score * 2 for score in passed]
print(passed)
print(doubled)
```

第一个列表推导式筛选及格成绩，第二个列表推导式对筛选结果做映射计算。

## 练习任务
- 用列表推导式取出成绩列表中的及格分数
- 用列表推导式把整数列表中的每个数平方

## 题目种子
- L1 `choice`：列表推导式最适合表达哪类逻辑？（答案：简单映射和筛选；引用：PY020:F003）
- L2 `short_answer`：说明 [x for x in nums if x > 0] 中 if 的作用。（答案：if 用于条件筛选，只保留满足条件的元素。；引用：PY020:F002）
- L2 `debugging`：判断正误：列表推导式不能加入条件筛选。（答案：错误。列表推导式可以加入条件筛选。；引用：PY020:F002）
- L3 `practice`：给定 nums，返回其中所有偶数组成的新列表。（答案：能写出 [x for x in nums if x % 2 == 0] 或等价代码。；引用：PY020:F002）
