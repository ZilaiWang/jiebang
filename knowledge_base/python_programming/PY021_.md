# PY021 字典方法进阶

- 模块：Python程序设计
- 难度：basic
- 摘要：get 方法可在键不存在时返回默认值。

## 可审核事实
- PY021:F001 — get 方法可在键不存在时返回默认值。
- PY021:F002 — items 方法可同时遍历字典的键和值。
- PY021:F003 — keys 和 values 可分别获取字典中的键集合和值集合视图。

## 教学示例

### 安全统计学生成绩

```python
scores = {"小明": 92, "小红": 85}
print(scores.get("小刚", "未找到"))
for name, score in scores.items():
    print(name, score)
```

get 避免键不存在时直接报错，items 适合同时处理姓名和成绩。

## 练习任务
- 用 get 查询不存在学生的成绩并返回默认提示
- 用 items 遍历字典并输出所有键值对

- L2 `debugging`：判断正误：items 只能得到键，不能得到值。（答案：错误。items 可同时得到键和值。；引用：PY021:F002）
