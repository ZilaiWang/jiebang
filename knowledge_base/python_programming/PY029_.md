# PY029 方法与对象状态

- 模块：Python程序设计
- 难度：intermediate
- 摘要：实例方法可访问并修改对象的实例属性。

## 可审核事实
- PY029:F001 — 实例方法可访问并修改对象的实例属性。
- PY029:F002 — self 通常表示当前实例对象。
- PY029:F003 — 把行为写成方法有助于让对象自己完成相关操作。

## 教学示例

### 用方法更新学生成绩

```python
class Student:
    def __init__(self, name, score):
        self.name = name
        self.score = score

    def update_score(self, new_score):
        self.score = new_score

student = Student("小明", 80)
student.update_score(92)
print(student.score)
```

update_score 是实例方法，通过 self 修改当前学生对象的 score 属性。

## 练习任务
- 为 Student 类添加 update_score 方法
- 写一个方法返回学生是否及格
