# PY022 集合运算

- 模块：Python程序设计
- 难度：basic
- 摘要：集合支持交集、并集和差集等运算。

## 可审核事实
- PY022:F001 — 集合支持交集、并集和差集等运算。
- PY022:F002 — 交集表示两个集合共同拥有的元素。
- PY022:F003 — 差集表示只存在于一个集合而不存在于另一个集合的元素。

## 教学示例

### 比较两个班报名名单

```python
class_a = {"小明", "小红", "小刚"}
class_b = {"小红", "小丽", "小刚"}
print(class_a & class_b)
print(class_a - class_b)
```

& 得到共同报名的学生，- 得到只在 A 班名单中的学生。

## 练习任务
- 求两个兴趣小组名单的共同成员
- 找出只在一个名单中出现的学生

## 题目种子
- L1 `choice`：两个集合共同元素组成的集合叫作什么？（答案：交集；引用：PY022:F002）
- L2 `short_answer`：说明 A - B 表示什么。（答案：差集表示只存在于 A 而不存在于 B 的元素。；引用：PY022:F003）
- L2 `debugging`：判断正误：集合差集表示两个集合所有元素合并。（答案：错误。差集表示只在一个集合中的元素。；引用：PY022:F003）
- L3 `practice`：给定两个名单集合，返回共同报名的人。（答案：能使用 & 或 intersection 求交集。；引用：PY022:F002）
