# Day4 · 三组学习者对比结果（三方面差异）

跑通方式：读 Day0 learners.json 三组画像，脚本 `scripts/day4-learner-comparison.py` 真实跑闭环，读 session 文件 `diagnosis_answer_key` 精确控制诊断作答，制造画像分层。每组带重试（最多 4 次）直到拿到决策动作。

## 一、路径是否不同 —— 不同

```text
林晓（零基础，目标"学习 for 循环"）：
  路径 = K007（for循环），1 个节点
  她只需要学 for 循环这一个知识点。

张伟（项目目标，目标"读成绩文件统计平均分"）：
  路径 = K007 → K009（for循环 → 列表），2 个节点
  他的目标要"循环遍历 + 列表存数"两个知识点，路径更长。

陈昊（基础薄弱，目标"成绩统计程序"）：
  画像 level=basic，规划目标 K009（列表），路径更聚焦。
```

三个人因为目标不同、画像不同，拿到**不同长度、不同终点**的学习路径。

## 二、资源难度是否不同 —— 不同

```text
陈昊（超自评，画像 level=basic）：
  诊断题含 basic 难度，资源难度更高。

林晓（零基础，画像 level=beginner）：
  诊断题全是 beginner 难度，资源从最基础开始。

张伟（项目目标，自评 intermediate）：
  诊断题含 integrated 难度（综合项目），资源覆盖到综合层级。
```

动态筛题让不同画像拿到**不同难度**的诊断题和资源。

## 三、反馈动作是否不同 —— 不同

```text
林晓（诊断答错 for循环）：
  反馈动作 = remediate（补救）—— 答错的知识点要重新补学。

张伟（诊断答错列表）：
  反馈动作 = reinforce（巩固）—— 薄弱点需要强化。

陈昊（诊断全对，画像 basic）：
  画像上调一档（beginner → basic），体现"客观上调"。
```

三个人因为客观作答不同，拿到**不同画像判定路径**（客观封顶 / 客观上调 / 画像冲突）和**不同反馈动作**（补救 / 巩固）。

## 四、画像 level 判定三机制全部真实触发

```text
① 客观封顶（林晓）：答错 beginner 题 → level 封顶 beginner
② 客观上调（陈昊）：全对含 basic → level 上调 basic（超自评）
③ 画像冲突（张伟）：自评 intermediate 但答错 basic → 画像漂移触发 reprofile
```

这就是 Day4 要证明的"动态诊断 / 画像反填 / 动态决策"——同一系统，三个学习者走三条完全不同的画像判定路径，拿到不同画像、不同路径、不同资源难度、不同反馈动作。

## 五、如实说明（模型稳定性）
